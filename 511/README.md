# 51短剧 影视仓 / TVBox 配置源

本仓库用于托管「51短剧」（blue.xdrgcewe.cc）的影视仓自建源，目录结构参照 clun.top 的可用源格式。

## 一、文件结构

```
.
├── 51duanju.json          ← 影视仓里填的就是这个文件的直链
├── lib/
│   ├── drpy2.min.js       ← JS 爬虫引擎
│   ├── template.js        ← 模板占位模块（引擎必需，勿删）
│   ├── json5.js           ← 引擎依赖（勿删）
│   ├── jinja.js           ← 引擎依赖（勿删）
│   ├── gbk.js             ← 引擎依赖（勿删）
│   ├── node-rsa.js        ← 引擎依赖（勿删）
│   ├── pako.min.js        ← 引擎依赖（勿删）
│   ├── cheerio.min.js     ← 备用
│   └── crypto-js.js       ← 备用
└── js/
    └── 51duanju.js        ← 51短剧专用规则（分类/搜索/详情/播放）
```

> `51duanju.json` 里站点用的是**相对路径**：`./lib/drpy2.min.js` 与 `./js/51duanju.js`。
> 因此 `lib/`、`js/` 两个目录**必须与 json 保持同级**，不要改动层级或重命名。

## 二、导入方法

1. 在 GitHub 上建一个 **Public（公开）** 仓库，把本目录下所有文件按原层级上传。
2. 打开仓库里的 `51duanju.json`，点右上角 **Raw**，复制地址栏链接，形如：
   `https://raw.githubusercontent.com/你的用户名/仓库名/main/51duanju.json`
3. 打开影视仓 → 顶部「配置」→ 粘贴上面的链接 → 确定 → 等 5～15 秒。
4. 首页出现「51短剧」，点进去应能看到 8 个分类和短剧海报。

### 国内直连打不开时

`raw.githubusercontent.com` 在国内常被拦截，把链接套一层加速前缀即可（下面二选一）：

- `https://gh-proxy.com/` + 原始链接
  例：`https://gh-proxy.com/https://raw.githubusercontent.com/你的用户名/仓库名/main/51duanju.json`
- `https://cdn.jsdelivr.net/gh/你的用户名/仓库名@main/51duanju.json`（jsDelivr）

相对路径会跟随加速域名一起解析，无需额外修改配置。

## 四、常见问题

- **只显示「51短剧」标题、没有内容**：说明引擎或规则没加载成功。检查 `lib/` 下 7 个依赖文件是否都上传了（`template.js`、`json5.js`、`jinja.js` 最容易漏），以及 `lib/`、`js/` 是否与 `51duanju.json` 同级。
- **点开分类转圈后为空**：多半是网络到不了接口域名。用设备浏览器打开 `https://wj-api-51dj.yvyjdhr.com/api/home/ping`，能返回内容说明网络正常；打不开就把设备 DNS 换成 `223.5.5.5`。
- **能进详情但点播放黑屏**：播放地址是**限时签名**的 m3u8，规则已在点播时实时换取，若仍失败可清除 App 缓存后重进。
- **改了仓库内容但 App 里没变化**：raw 有缓存，在配置地址后加 `?v=2` 再导入一次即可刷新。
